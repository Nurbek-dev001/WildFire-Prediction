# Облако: ночной прогноз, сайт и Telegram-бот

После этой настройки компьютер больше не нужен. Каждую ночь GitHub Actions считает прогноз,
обновляет сайт на Cloudflare Pages, а бот на Cloudflare Workers утром рассылает тревоги
подписчикам. Всё на бесплатных тарифах.

```
23:40 UTC  GitHub Actions ─ прогноз v6 и v7 ─┬─ журнал → ветка forecast-log (отметка времени)
(04:40 KZ)  (3 попытки до 03:40 UTC)         └─ сайт → Cloudflare Pages
                                                       │ bulletin-latest.json
каждые 2 мин 00–09 UTC  Cloudflare Worker ─────────────┘→ рассылка подписчикам в Telegram
круглосуточно           Telegram → Worker: /today, /regions, геолокация, /settings
```

## Что сделать один раз (около 15 минут)

Пароли и ключи вводите только вы и только в эти три места; в коде и в чатах их нет.

### 1. Cloudflare (бесплатно, без карты)

1. Зарегистрируйтесь на <https://dash.cloudflare.com/sign-up>.
2. Откройте **Workers & Pages** один раз: Cloudflare предложит выбрать поддомен
   `*.workers.dev` — выберите любой.
3. Справа на странице **Workers & Pages** скопируйте **Account ID**.
4. **My Profile → API Tokens → Create Token → Create Custom Token**, права уровня Account:
   - Cloudflare Pages — Edit
   - Workers Scripts — Edit
   - Workers KV Storage — Edit

   Создайте токен и скопируйте его (он показывается один раз).

### 2. Telegram-бот

1. В Telegram откройте **@BotFather** → `/newbot`.
2. Имя, например «Steppe — пожарный прогноз»; адрес, например `SteppeFireKZ_bot`.
3. Скопируйте токен бота.
4. По желанию: `/setdescription`, `/setuserpic`.

### 3. GitHub: секреты

Репозиторий → **Settings → Secrets and variables → Actions → New repository secret**:

| Имя | Значение |
|---|---|
| `CLOUDFLARE_API_TOKEN` | токен из шага 1.4 |
| `CLOUDFLARE_ACCOUNT_ID` | Account ID из шага 1.3 |
| `TELEGRAM_BOT_TOKEN` | токен бота из шага 2.3 |

По желанию, вкладка **Variables**: `TELEGRAM_ADMIN_CHAT_ID` — ваш chat id (узнать у
@userinfobot); тогда команда `/stats` покажет вам число подписчиков.

### 4. Первый запуск

1. **Actions → Nightly forecast → Run workflow.** Через 10–20 минут сайт будет на
   `https://steppe-wildfire.pages.dev` (если имя занято, Cloudflare добавит суффикс; адрес
   виден в Cloudflare → Workers & Pages).
2. **Actions → Telegram bot → Run workflow.** Бот подключится к сайту и Telegram.
3. Откройте бота в Telegram → `/start` → выберите области.

Дальше всё идёт само. Задачу в Планировщике Windows регистрировать **не нужно**: два
выпуска (ПК и облако) писали бы в журнал наперегонки.

## Что умеет бот

| Команда | Что делает |
|---|---|
| `/start` | приветствие и выбор областей (кнопками, можно несколько или все) |
| `/today` | прогноз на завтра по вашим областям: до 10 тревог с координатами и ссылкой на карту |
| 📍 геолокация | тревоги в радиусе 50 км от вас, ближайшие первыми |
| `/regions` | изменить области |
| `/settings` | утренняя рассылка вкл/выкл, писать ли в дни без тревог, язык (рус/қаз/eng) |
| `/about` | что это и насколько точно; напоминание, что это не официальное предупреждение, 112 |
| `/stop` | отписаться, данные удаляются |

Утренняя сводка приходит, как только опубликован новый прогноз (обычно 05:00–06:00 по
Казахстану). Тревоги на пашне подписаны: там это обычно плановый пал. Бот хранит только
номер чата, язык, области и две настройки; заблокировавшие бота удаляются автоматически.

## Если что-то сломалось

- **Прогноз не вышел.** GitHub пришлёт письмо о неудачном запуске. Подробности — в
  Actions и в `status.json` ветки `forecast-log`. Ночь, не выпущенная к 03:40 UTC, пишется в
  журнал как `missed` с причиной.
- **Проверить вручную:** Actions → Nightly forecast → Run workflow (с флагом *replay* —
  пересчёт без записи в журнал).
- **Лимиты бесплатных тарифов:** GitHub Actions в приватном репозитории — 2000 минут в месяц
  (прогноз тратит около 15 минут в сутки); Cloudflare Pages — 500 публикаций в месяц
  (нужна одна в сутки); бот рассылает до 40 сообщений каждые 2 минуты — около 10 000 в утро.

## Где лежат данные

| Что | Где | Кто видит |
|---|---|---|
| код | ветка `main` | вы (репозиторий приватный) |
| замороженные модели и входные данные (~120 МБ) | ветка `forecast-inputs` | вы |
| карты прошлых лет (~260 МБ) | ветка `site-assets` | вы |
| журнал прогнозов, ежедневные карты | ветка `forecast-log` | вы |
| сайт, сводка тревог | Cloudflare Pages | все (это сам продукт) |
| подписчики бота | Cloudflare KV | только вы |
