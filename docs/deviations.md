# Assumptions, scope and deviations

1. **Real source acquisition/preparation is explicit.** No national archive or credentials were supplied. The shipped runnable experiment uses artificial spatial patches, not a fabricated Kazakhstan boundary. Real runs require normalized source contracts, original source manifests and an authoritative boundary. Source-specific national extraction and downloads have not been executed or validated. This is an implementation and synthetic verification, not a completed country-scale study.
2. **Demonstration compute is reduced by named configuration.** The primary defaults retain the requested tuning/bootstrap budgets, development years and buffered folds. The synthetic YAML reduces trials, tree counts and bootstrap repeats. This is a smoke-test configuration, not a replacement primary experiment.
3. **Publication lag requires real metadata.** The default minimum lag is a configuration assumption. Actual later availability always takes precedence. End-exclusive complete-day summaries available exactly at midnight enter only later targets because the user requires strict inequality. Reanalysis-derived results cannot be described as an operational forecast without an archive of information actually available then.
4. **TreeSHAP output compatibility.** The forecast winner is selected across all models/baselines. Explanations use the highest development-ranked XGBoost/CatBoost model, explicitly identified in `selection.json`. Random Forest TreeSHAP is additive on probability, not log-odds; applying a logit to its SHAP values would be incorrect. Exact raw-log-odds TreeSHAP therefore uses a margin-producing boosted model. Grouped ablations use the same predeclared explainable tree.
5. **Nested evaluation is stricter than simple tuning-on-fold-validation.** Each outer temporal/spatial fold tunes on chronological splits inside its training data. Development boosting validation alone controls early stopping; its selected tree count is fixed before final fitting.
6. **Geographic folds are deterministic contiguous bands of whole blocks.** They depend only on development geography. Training footprints must be at least the buffer distance from complete held-out block polygons. This is reproducible without outcome-based clustering; evaluate the fold geography on the real boundary.
7. **Sampling stage writes the plan; training folds execute it.** A single national presample before splitting would conflict with training-only resampling. Exact probabilities are recomputed from each fold view, and training tables retain q and inverse-q weights. Evaluation may use representative probability samples with weights when its row budget is exceeded.
8. **Sensitivity runs are explicit experiments.** Event-distance/time counts and block-size CV are automatic. The regional 1 km grid and class-weighting alternative require their own YAML/output directory, compatible source tables and a separately executed run. Historical-road sensitivity requires genuine historical snapshots. No such unavailable sensitivity data is invented.
9. **SHAP sample is descriptive.** High scores and errors are intentionally included alongside a deterministic random sample. The displayed mean absolute SHAP summarizes that explanation sample; it is not an unbiased national attribution estimate. Use representative weighted explanation sampling for population summaries.
10. **External corroboration and fire-weather indices are optional and absent.** No burned-area/official-incident data or prior-only FWI was supplied. Neither enters predictors or substitutes for event labels.
11. **Validation scope is explicit.** The synthetic run tests code and artifact contracts. It cannot establish real-data suitability, scientific conclusions, archive-wide runtime, 32 GB national feasibility, or deployment readiness. Missing regional metadata is flagged rather than assigned a plausible region.
