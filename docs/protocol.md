# Frozen experiment protocol

Targets are UTC cell-days in the past-only new-event risk set. Positives are the cell and UTC day of the deterministic earliest detection of a transitive connected event. Spatial and temporal edge limits are inclusive. Ties sort by timestamp, projected coordinates and cell ID; a stable hash names each event. Events may bridge arbitrarily long periods by chains of admissible links, which is why distance/time sensitivity is retained.

The industrial exclusion list is derived once from development-period persistent detections intersecting a development-dated nonvegetated mask. The frozen list is reused when test labels are released. Detections are never predictors. Final label processing can use later detections for event grouping only; first detections predating a holdout remain nonpositive in that holdout.

Development spans 2015–2021. Outer chronological validations train through the preceding year and validate in 2019, 2020 and 2021. Independent spatial evaluations hold whole 100 km blocks in five contiguous geographic folds and exclude training cell footprints within 25 km of held-out block polygons. The same procedure is repeated with 50/150 km blocks. Model selection averages outer-fold AP using representative validation weights. Spatial sensitivity scores are reported separately and do not select the primary winner.

Within every outer training view, Optuna tuning uses chronological development-only inner validation. Training-only reservoirs retain all positives; negative quotas depend on calendar month and broad land cover. Rows have `q` and `weight=1/q`. The seasonal predictor uses weighted counts with shrinkage toward development prevalence. Logistic models use fixed L2 regularization; ensembles tune complexity and regularization. Median imputation and standardization are fitted only on the corresponding training view. All correlated groups remain available; no automatic correlation dropping occurs.

Calibration fits a sigmoid to clipped raw model log-odds using only representative 2022 data. The threshold maximizes weighted F1 on that same reserved year, as requested; resulting test estimates account for no extra threshold fitting. Ties choose the highest threshold. Weighted calibration probability quantiles define map classes and are frozen with the threshold.

The final `evaluate` stage records hashes of the fitted models, calibration choices and ablations before requesting test source rows. All tests use the frozen choices. BSS uses the development-fitted smoothed seasonal reference, not the test prevalence. AP is the recall-increment definition, distinct from trapezoidal integration. Undefined metrics remain null/empty, not fabricated zeros. Empty reliability bins retain their counts. Paired bootstrap resampling uses identical spatial-block × time-block multiplicities for every model; differences are A minus B. Degenerate resamples are omitted per metric and counted explicitly. Reliability frequency intervals use the same space-time units. Capture rates rank cells daily by predicted probability and select an area budget, recording any boundary-cell overshoot and false-alert area-days.

GeoTIFF band 1 stores calibrated probability, band 2 the calibration-fixed class; -9999 is nodata. The map predicts every eligible cell rather than interpolating point detections. Ineligible cells are outside the estimand and stay nodata. Class frequencies are evaluated without changing boundaries.

AccessGuard is a pipeline integrity check, not a cryptographic or operating-system security barrier. Ingestion may hash opaque files containing future data, and synthetic generation necessarily writes future fixtures, but no prefinal stage is authorized to materialize their held-out observations. A user with raw filesystem access can bypass the API; the reproducibility record makes the intended sequence auditable.
